Instructions

Please read the instructions carefully

  1. The total duration of the examination is minutes. The countdown timer at the top right shows the remaining time. The exam is submitted automatically when the timer reaches zero.
  2. The paper has questions carrying marks in two sections: General Aptitude (GA) and Civil Engineering (CE). Use the section tabs to move between them.
  3. Question types:
    • MCQ – Multiple Choice: exactly one correct option. Negative marking: −1/3 for a wrong 1-mark answer and −2/3 for a wrong 2-mark answer.
    • MSQ – Multiple Select: one or more options are correct. Full marks only if all correct options and no wrong option are chosen. No negative marking; no partial credit.
    • NAT – Numerical Answer Type: type a number using the keyboard or on-screen keypad. No negative marking.
  4. An answer is recorded only when you click Save & Next or Mark for Review & Next. Moving to another question through the palette without saving will not save your selection.
  5. Questions that are answered and marked for review are evaluated. Questions only marked for review (no answer) are not.
  6. A virtual scientific calculator is available from the top bar. Personal calculators are not allowed.
